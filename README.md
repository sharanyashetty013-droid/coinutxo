# 🪙 CoinUtxo

**CoinUtxo** is a modern cryptocurrency security dashboard designed to track, analyze, and visualize unspent transaction output (UTXO) threat feeds and security alerts in real time.

🌐 **Live Website:** [coinutxo.vercel.app](https://coinutxo.vercel.app)

---

## Key Features

- **Security Alerts & Threat Feed:** Real-time visibility into cryptocurrency threat updates.
- **UTXO Tracking:** Clear insight and data visualization for unspent transaction outputs.
- **Responsive Interface:** Tailored for both desktop and mobile views with light and dark mode support.

---

## Tech Stack

- **Framework:** Next.js (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Deployment:** Vercel

---

## How to Run Locally

```bash
# 1. Clone the repository
git clone [https://github.com/sharanyashetty013-droid/coinutxo.git](https://github.com/sharanyashetty013-droid/coinutxo.git)

# 2. Go into the project directory
cd coinutxo

# 3. Install dependencies
pnpm install

# 4. Start the development server
pnpm dev

Open http://localhost:3000 in your browser to view the application.
